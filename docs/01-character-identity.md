# 01 · Character Identity and Approval

**Status:** Draft for review. No character master has been approved.

## 1. Design objective

Create one original, broadly usable chat-sticker character. The character should work across everyday reactions, greetings, gratitude, celebration, awkward moments, humor, reassurance, and mild frustration.

The character must not be tied to a company, industry, profession, or specific workplace identity.

## 2. Visual principles inherited from the Notion design system

The Notion Editorial collaboration rules and Visual Style Library V4 suggest these transferable principles:

- One clear visual subject; decoration must not compete with the character.
- Deliberate color hierarchy and restrained palette.
- Stable line quality, material treatment, proportions, and visual center.
- Strong recognition at small display sizes.
- Every visual detail should support the intended expression.
- A polished result can remain warm and hand-drawn; polish does not require glossy 3D rendering.

Relevant style references:
- S36 · Soft storybook hand drawing: a promising candidate for the core character language. Its palette and rounded hand-drawn forms can support warmth and broad emotional range. The card is still marked unverified.
- S38 · Mouse Doodle: a deliberately rough, awkward, humorous language. Better treated as an optional comedy series than the default identity.
- S63 · Photo plus doodle: a possible special treatment for object-based or scene-based stickers, not the default character system.

These are references, not approved production settings.

## 3. What can be learned from the existing sticker references

The previous sticker set contains a recurring visual direction:
- warm brown hand-drawn outlines
- chestnut / dark brown hair, often tied up
- soft rounded facial features
- cream, beige, and muted coral clothing
- expressive faces and simple gesture marks

However, face shape, hair silhouette, body proportions, outfit details, and props vary. The set is useful as a reference pool, but it does not yet define a single canonical character.

## 4. Candidate directions to compare

Create three controlled candidates using the same character brief and the same expression set.

### A · Soft storybook character
- rounded forms and gentle hand-drawn outlines
- warm cream base with a restrained accent palette
- expressive but composed face
- polished, tactile, approachable appearance
- closest to the spirit of S36

### B · Clean minimal chibi
- simplified silhouette and fewer internal details
- highly legible facial expressions
- stronger shape language and compact composition
- optimized for very small chat display

### C · Loose doodle character
- intentionally irregular strokes and imperfect proportions
- exaggerated expressions and comic timing
- spontaneous, slightly absurd humor
- inspired by S38; suitable for a separate series

Do not mix all three directions into one master. Compare them as separate candidates.

## 5. Character model-sheet requirements

Each candidate should be presented on one model sheet containing:

### Identity views
- front view
- three-quarter view
- side view
- neutral standing pose

### Face and expression tests
- happy
- embarrassed
- surprised
- confused
- tired
- frustrated
- touched / grateful
- determined

### Gesture tests
- wave
- nod
- thumbs-up
- hands together
- shrug
- applause

### Identity controls
- face silhouette
- eye shape and spacing
- eyebrow language
- nose and mouth construction
- hairstyle silhouette and hairline
- head-to-body ratio
- hand and foot proportions
- outfit silhouette
- outline thickness and texture
- fixed palette with color values

### Export and legibility tests
- transparent-background PNG
- full-size review
- 240 px preview
- 96 px preview
- silhouette-only review
- grayscale review

## 6. Approval scorecard

Score each candidate from 1 to 5. A candidate should not be approved solely because its first image looks attractive.

| Criterion | Review question |
|---|---|
| Small-size recognition | Can the character be recognized at chat size? |
| Emotional range | Can the face and body express subtle and strong emotions? |
| Identity stability | Can the design be reproduced without drift? |
| Distinctiveness | Is the silhouette recognizable among generic sticker characters? |
| Warmth and appeal | Does it feel approachable without becoming childish? |
| Series scalability | Can it support dozens of poses and props? |

The user makes the final selection. The selected model sheet becomes the single identity reference for production.

## 7. Fixed vs. variable attributes

Fixed after approval:
- face construction
- hairstyle silhouette and color
- head/body ratio
- base outfit language
- linework and shading
- core palette

Allowed to vary:
- expression
- gesture
- pose
- camera crop
- prop
- caption
- animation timing

A one-off redesign requires explicit approval and a new version.
