# 01 · Character Identity and Approval

**Status:** User-reference-first workflow. No default mascot is imposed.

## 1. Core principle

The user supplies the person, pet, illustration, or existing character they want represented. The system converts that reference into one consistent sticker character.

Do not ask the user to choose between unrelated character concepts when they have supplied a reference. Do not start by inventing three mascots.

## 2. Reference intake

Accept personal photographs, photos of another person or a pet, existing cartoons / illustrations, avatars, and sticker images. Optional style and layout references may also be supplied.

When multiple images are supplied:
- identify which image best establishes the face and overall identity
- use other images to clarify hairstyle, clothing, profile, or distinctive details
- do not combine different people into one character without explicit instruction
- ask one focused question only when the intended subject cannot be determined

## 3. Identity extraction

Record visible, useful design traits:
- face / head silhouette
- hairstyle silhouette, hairline, and color
- eyebrow and eye shape
- nose and mouth construction
- distinctive visible marks, accessories, or glasses
- body and head proportions
- clothing silhouette and color cues
- posture or characteristic gesture, where relevant

Keep the result recognizable to the supplied reference while adapting it to a coherent sticker illustration. Do not invent identity traits that are not visible or supplied.

## 4. Visual rules inherited from Notion

Use the Notion Editorial collaboration rules and Visual Style Library V4 as visual-quality guidance:
- one clear visual subject; decoration must not compete with the character
- deliberate color hierarchy and restrained palette
- stable line quality, material treatment, proportions, and visual center
- strong recognition at small display sizes
- every detail should support the expression
- warm hand-drawn rendering can be polished without becoming glossy 3D

Relevant references:
- S36 · Soft storybook hand drawing: rounded forms, warm palette, approachable hand-drawn treatment. Style reference, not mandatory default.
- S37 · Chinese 16-cell chat stickers: character image plus optional sticker-sheet layout reference, varied expressions, coordinated batch.
- S38 · Multilingual sticker pack: batch workflow and variation in expression / caption density.
- S63 · Photo plus doodle: optional treatment when the user wants a real photographed object or scene combined with drawn expressions.

S37 and S38 are marked unverified in Notion. Reuse their production logic selectively; do not assume their visual outputs have been validated.

## 5. Proposed character lock sheet

After analyzing the reference, create one proposed model sheet containing:
- front and three-quarter views; side view where useful
- neutral full-body pose
- face silhouette, hairstyle silhouette and color
- eyes, brows, nose, mouth, and distinctive visible features
- head/body ratio
- outfit language and key colors
- line weight, texture, and shading approach
- a small expression-range test: happy, embarrassed, surprised, confused, tired, frustrated, grateful, determined

The purpose is to test whether the same person remains recognizable across expressions, not to ask the user to select a new character concept.

## 6. Approval checkpoint

Present the single proposed character model sheet and ask:

“这个人物原型是否符合你提供的参考形象？确认后我会锁定五官、发型、比例、服装语言和画风，再按你确认的表情清单制作。”

If the user requests changes, revise the same model sheet. Do not generate alternative unrelated mascots unless requested.

Once approved:
- assign a character ID and version
- save the model sheet as the identity reference
- record fixed identity attributes
- use the same reference in all later sticker batches and animation frames

## 7. Fixed vs. variable attributes

Fixed after approval: face and head construction, hairstyle silhouette and color, distinctive visible features, head/body ratio, base outfit language and palette, linework, texture, and rendering.

Allowed to vary: facial expression, gesture, pose, camera crop, prop, caption, and animation timing.

A deliberate identity redesign requires explicit user approval and a new character version.
