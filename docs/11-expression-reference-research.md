# 11 · Expression Reference Research

**Purpose:** Use public examples to improve expression ideas and pack progression when the user is uncertain, while preserving the user's character identity, style, and creative control.

## 1. When to research

Use web search when:
- a phrase has several plausible emotional readings and examples would help distinguish them
- the user asks for inspiration or says they are unsure what a sticker should look like
- a pack needs better coverage, progression, or less repetitive expressions
- a gesture, pose, or chat convention is unfamiliar

Do not search by default when the user has already specified the intended meaning and visual action clearly. Do not delay straightforward production with unnecessary research.

## 2. Search approach

Search for public visual examples and usage context using combinations of:
- exact phrase or equivalent phrase
- intended emotion and social tone
- gesture / facial expression
- chat sticker or messaging context
- pack / sequence / reaction examples

Prefer original creator pages, public sticker packs, and sources with clear context. Use more than one example when the phrase is ambiguous. Search results are inspiration, not approval.

## 3. What to extract

Record only general, reusable observations:
- common facial cues and gesture choices
- emotional intensity and social tone
- setup → reaction → peak → hold, where useful
- typical chat situation
- ways to distinguish the expression from nearby items in the same pack

A pack may have a progression in emotional intensity or chat situation, but a narrative arc is optional. Optimize for useful, distinct chat reactions rather than a forced story.

## 4. Copyright and originality

- Do not copy another creator's character, distinctive illustration, signature composition, or complete sticker.
- Do not trace or recreate a found image as a near-identical derivative.
- Use references to understand broad expression conventions, gesture logic, or pack coverage.
- Preserve the user's approved character identity and visual style as the controlling references.
- Record source URLs and a short note describing the general idea borrowed.

## 5. Approval

When research materially changes the proposed interpretation, show the user a compact definition list and obtain approval before final generation. If the user has already approved the phrase and meaning, research may refine the acting details without reopening the entire list.
