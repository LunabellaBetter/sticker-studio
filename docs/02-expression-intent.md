# 02 · Expression Intent Specification

**Purpose:** Translate what the user means into a visual performance that viewers interpret correctly.

A phrase alone is insufficient. The same words can carry different emotions, social intent, and intensity.

## 1. Expression brief

For every sticker, record:

| Field | What to define |
|---|---|
| Sticker phrase | Exact visible words, if any |
| Literal meaning | What the words say |
| Communicative act | Acknowledge, reassure, thank, refuse, tease, celebrate, comfort, etc. |
| Underlying emotion | Happy, relieved, embarrassed, annoyed, touched, uncertain, exhausted, etc. |
| Intensity | 1–5, from restrained to exaggerated |
| Social tone | Warm, neutral, playful, sarcastic, formal, intimate, awkward |
| Context | What happened immediately before the sticker is sent |
| Intended reading | What the recipient should understand |
| Misreading to avoid | The interpretation the image must not suggest |
| Face | Eyes, brows, mouth, cheeks, gaze direction |
| Body | Posture, shoulders, hands, head angle |
| Motion | The action that makes the emotion legible |
| Caption treatment | Bubble, hand lettering, standalone text, or no text |

## 2. Example: one phrase, multiple meanings

The phrase “收到” can express different things:

| Intent | Face | Body language | Motion |
|---|---|---|---|
| Warm acknowledgement | Soft smile, bright eyes | Small nod, relaxed shoulders | One clear nod, slight settle |
| Neutral confirmation | Calm eyes, closed-mouth expression | Upright posture | Short nod, minimal movement |
| Reluctant acceptance | Uneven smile, slightly lowered brows | Small shoulder drop | Pause, slow nod |
| Overwhelmed acknowledgement | Wide eyes, tense smile | Hands full or shoulders raised | Quick nod, slight wobble |

The user must select the intended meaning before production. The system should not choose based on the phrase alone.

## 3. Emotion-to-body translation

Use coordinated cues rather than relying on the mouth alone.

- Joy: lifted cheeks, open eyes, raised posture, outward gesture.
- Embarrassment: averted gaze, softened shoulders, small hand movement, blush.
- Frustration: compressed brows, tight mouth, restrained or abrupt gesture.
- Surprise: raised brows, widened eyes, brief recoil, then hold.
- Gratitude: softened gaze, slight bow or hands together, gentle follow-through.
- Exhaustion: lowered eyelids, dropped shoulders, delayed movement, longer hold.
- Uncertainty: asymmetrical brows, side glance, slight head tilt, small pause.

These are starting hypotheses. Adjust them to the user's intended tone and the approved character language.

## 4. Semantic review

Before illustration, ask:
1. If the caption is hidden, does the face and gesture still communicate the intended emotion?
2. If the image is seen without context, is the likely interpretation close to the user's intent?
3. Does the intensity match the phrase and relationship?
4. Could the pose be read as sarcastic, dismissive, angry, or flirtatious unintentionally?
5. Is the expression distinct from other stickers in the set?

If the meaning changes when the caption is removed, review whether the image is carrying enough emotional information.

## 5. User feedback vocabulary

When the user reviews a draft, capture corrections as explicit dimensions:
- too strong / too weak
- too cute / too childish
- too stiff / too exaggerated
- expression wrong
- gesture wrong
- timing too fast / too slow
- pause too short / too long
- caption does not match
- character identity drift

Convert feedback into a revision to the expression brief or storyboard. Do not respond by changing unrelated visual attributes.
