# Sticker Studio

A general-purpose creative system for designing, animating, reviewing, and packaging expressive chat stickers.

The project is organized around two quality gates:

1. **Character identity** — establish and approve one reusable character master before producing a large sticker set.
2. **Expression and motion** — translate the user's intended meaning into facial acting, body language, key poses, timing, and a seamless loop.

## Current status

**Foundation draft · 2026-11-05**

- The repository is intentionally general-purpose.
- No company, profession, or brand identity is built into the character.
- Existing sticker images may be used as visual references, but none is yet the approved master.
- Character style and identity remain pending user approval.
- Animation guidance is documented; no new GIF is marked as approved.

## Working principle

**Understand the expression before drawing it. Lock the character before multiplying outputs. Design key poses before generating in-between frames.**

A sticker is successful when its meaning is understood quickly at chat size, the character remains recognizable, and the motion feels intentional rather than mechanically repeated.
