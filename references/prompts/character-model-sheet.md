# Character Model Sheet Prompt Template

Use this template only after the user has supplied character references. The user's reference defines the character; do not invent alternative mascots.

```text
Create one polished character model sheet for a chat sticker series.

IDENTITY SOURCE
Use the supplied character reference as the sole identity source. Preserve the recognizable face silhouette, hairstyle and hairline, eye shape, age impression, proportions, distinctive accessories, and approved outfit cues.

STYLE
Use the user-approved visual style reference for line quality, texture, palette, and rendering only. Do not let the style reference replace the character identity.

MODEL SHEET CONTENT
- front view
- three-quarter view
- side view when needed
- neutral full-body pose
- clear close-up of the face
- expression tests: happy, surprised, confused, frustrated / pouty, embarrassed, tired, crying, grateful
- a small gesture test: wave, nod, thumbs-up, hands together

COMPOSITION AND QUALITY
- high-resolution master, 1024 px or larger on the long edge
- character large enough to inspect facial construction and outfit details
- clean, readable silhouettes
- consistent head/body ratio across views
- restrained background that does not compete with the character
- no unrequested captions, logos, or decorative objects
- no unrelated characters or alternative concepts

The sheet is a design and identity approval artifact. Do not treat it as a finished sticker pack.
```
