# Individual Sticker and GIF Prompt Template

Use one prompt per sticker. Never ask an image generator to place unrelated stickers into one final GIF.

```text
Create ONE independent chat sticker using the approved character model sheet as the identity anchor.

CHARACTER LOCK
Preserve the approved face construction, hairstyle, hair color, age impression, proportions, outfit cues, linework, texture, and palette. Do not redesign the character.

STICKER INTENT
Visible caption: [EXACT TEXT OR NONE]
Intended meaning: [WHAT THE USER WANTS TO COMMUNICATE]
Emotion and intensity: [EMOTION, 1–5]
Social tone: [TONE]
Typical chat context: [CONTEXT]
Misreading to avoid: [UNWANTED READING]
Distinct from existing pack items by: [INTENT / FACE / GESTURE / MOTION / CONTEXT]

FACIAL ACTING
Eyes: [SHAPE / GAZE / CHANGE]
Brows: [POSITION / CHANGE]
Mouth: [SHAPE / CHANGE]
Cheeks: [BLUSH / TENSION]
The facial expression must communicate the intent even without the caption.

BODY ACTING
Posture: [POSE]
Hands: [GESTURE]
Shoulders / torso: [ACTION]
Prop: [OPTIONAL]

COMPOSITION
- one character, one sticker, one communicative intent
- transparent background
- large character scale; avoid excessive empty space
- high-resolution master, 1024 px or larger on the long edge
- strong silhouette and readable details
- caption stays clear of the face and remains legible
- do not add a permanent title above the character unless requested
- if text is useful, reveal it at the planned emotional beat and hold it steadily afterward
- avoid repeating the same phrase in multiple locations
- no panels, contact-sheet grid, neighboring sticker, or colored backplate unless requested

ANIMATION (if GIF)
Create a clear opening pose, anticipation, main action, emotional peak, follow-through, readable hold, and a natural loop transition.
The animation must be distinct from the nearest existing stickers in the pack; do not reuse their full facial / gesture / motion combination.
Change the face meaningfully; do not rely on head wobbling or idle bobbing.
Keep canvas, character scale, identity, caption, and transparency consistent across frames.

OUTPUT
Export this sticker as its own independent PNG and/or GIF. Do not include any other sticker in the file.
```
