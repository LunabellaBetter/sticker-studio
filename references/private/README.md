# Private Reference Assets (Local Only)

Store private character references here. This directory is Git-ignored except for this README.

Suggested layout:
- `character/approved-model-sheet.png`
- `character/character-lock.md`
- `motion/approved-speechless.gif`
- `motion/approved-thumbs-up.gif`
- `manifest.yml`

Do not force-add private photos or derivative likeness assets to the public repository. Public distribution requires explicit permission from the person or the child's parent / legal guardian.
