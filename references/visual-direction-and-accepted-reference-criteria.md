# Visual Direction and Accepted Reference Criteria

This document records reusable visual-quality decisions from the current sticker production test. It describes production criteria, not a default character identity or a mandatory art style for every project.

## 1. Accepted visual direction

For the current approved reference set, the user accepted:
- warm hand-drawn pencil / crayon rendering
- expressive dark sketch outlines with subtle texture
- soft, warm skin shading and restrained blush
- lively, readable eyes and mouth acting
- a friendly, playful sticker tone
- varied compositions that support each expression

This direction is a reference for this series. New projects must follow the style reference selected by their own user.

## 2. User feedback translated into production rules

The recent batch was visually close to the desired direction, but the character appeared too small and the artwork lacked sufficient detail at chat size.

Required adjustments:
- increase the character's scale within the canvas
- reduce unused empty margins
- make the face and gesture easier to read
- generate / compose at a larger master resolution
- preserve line texture and facial detail during export
- use transparent backgrounds for finished chat stickers unless a background is explicitly requested
- avoid using a solid colored rectangle as a default sticker background

Do not simply upscale a small image. Recompose or regenerate at a larger source size, then export at the target size.

## 3. Motion references

The approved motion references establish these quality expectations:
- the face performs the emotion
- the hands and body reinforce the expression
- the action has a readable beginning, peak, and settle
- the loop feels deliberate
- one GIF contains one sticker / one communicative intent

## 4. Reference precedence

When references conflict, use this order:
1. current user's explicit instructions and approvals
2. approved character model sheet for identity
3. approved style reference for rendering
4. approved GIF reference for motion quality
5. layout references for contact-sheet organization only

A motion or style reference must never alter the approved character identity.
